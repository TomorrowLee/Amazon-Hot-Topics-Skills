# 从采购报价到账面贡献

统一站点、币种、销售单位与日期。例如两件装从售价到运费都按整套计算。把平台计费器估算、实际账单、供应报价与假设情景列成不同来源。对不同采购量、汇率、头程和退货情景分别计算，再比较影响最大的变量。

| 输入字段 | 单件口径 |
|---|---|
| `currency`、`net_price` | 币种用三位大写代码。净售价为折后不含代收税的销售收入，退货影响在下方单列。 |
| `product_cost`、`inbound_freight`、`duty` | 对应销售单位的采购成本、头程与关税。用报价阶梯、重量、贸易条款和汇率日期核对已含项目。 |
| `packaging`、`marketplace_fee` | 包材与平台佣金等交易费用。标注平台、类目、计费档位及报价日期。 |
| `fulfillment` | 每售出一件的履约费，注明 FBA、第三方仓或自发货口径。 |
| `expected_return_loss` | 平均每笔发出订单的退货损失。按有依据的退货率、退款、逆向运费、可回收价值和已返还平台费核对；各项只计一次。 |
| `other_variable`、`ads` | 其他单件变动费用、分摊到每笔发出订单的广告支出。取同一归因或结算期。 |

**广告前单件贡献**为净售价减去除广告外的全部单件变动费用。该值为零或正数时，也是单件广告支出的盈亏平衡上限。该值为负时，即使广告支出为零，单件仍亏损。

**广告后单件贡献**为广告前贡献再减广告分摊。将广告后贡献除以净售价，得到贡献率。固定费用、所得税和资金占用需要另算。平台估计毛利率保留其原始字段和计算口径。

## 可复算的小例子

把下列演示数据存为 `unit-input.json`，在技能目录运行 `python scripts/unit_economics.py unit-input.json`。所有数值均为虚构美元金额，仅演示口径。

~~~json
{
  "currency": "USD", "net_price": 28, "product_cost": 6,
  "inbound_freight": 1.2, "duty": 0.8, "packaging": 0.5,
  "marketplace_fee": 4.2, "fulfillment": 4.5,
  "expected_return_loss": 0.8, "other_variable": 0, "ads": 3
}
~~~

结果为广告前贡献 10.00 美元，广告后贡献 7.00 美元，贡献率 25.00%。把 `ads` 改为 `null` 后，仍可算广告前贡献，广告后贡献和贡献率留空。把头程改为 `null` 后，两个贡献指标都留空，并列出缺项。

只有确认无此费用或已在另一字段完整计入且有说明时才填 0。缺失字段、省略字段、`null` 和“未获取”会列入 `missing`；输出中的 `null` 在报告中写“未获取”，负广告前贡献导致的广告上限留空则写“广告为零仍亏损”。金额显示两位小数，计算用原始精度。币种换算应在输入前完成，并保留汇率依据。
