## 需求与实物对照

每个方向填写一张。以下字段可随项目模板归入单独证据表。

| 记录项 | 内容 |
|---|---|
| 买家任务 | 谁，在什么限制下，完成哪一步时失败？ |
| 当期第一手证据 | 编号、可定位的原始链接、发布日期、抓取日、地区、独立经历与同源关系 |
| 已有支出或补救 | 已付费 / 愿意付费 / DIY / 单纯抱怨；分别给出依据 |
| 匹配实物与替代品 | 两个当地搜索词；在售链接、目标站、货币价格、规格、日期、匹配程度与差异 |
| 竞争与反证 | 已解决部分、最强反例、搜索或销量的来源和统计口径 |
| 供应与成本 | 包装、适配、报价条件、单件贡献、费用口径、数据缺口与来源 |
| 初筛与下一步 | 已满足 / 已证实不符 / 待核验的条件；最省成本的下一项测试、通过及放弃条件 |
| 审核 | 当前处理状态、需用户复核的事项、最终决策留空 |
