# 跨境电商-last 30days Skills

给跨境卖家用的近 30 天需求研究技能。输入市场和购买场景，可得到一张有原帖、有在售对照、有反证的选品机会卡，判断下一笔验证成本该花在哪里。

## 安装和使用

本仓库根目录就是完整技能包。在支持 Agent Skills 的环境中运行以下命令即可安装。

~~~sh
npx skills add TomorrowLee/Amazon-Hot-Topics-Skills --skill crossborder-ecommerce-last30days
~~~

手动安装到 Codex 项目时，将本仓库的技能文件复制到 `.agents/skills/crossborder-ecommerce-last30days/`，确保 `SKILL.md` 直接位于该目录，并保留各子目录。运行需要能检索公开资料的宿主，平台销量、关键词或履约费用还需要相应数据权限。可选的上游研究引擎需单独安装和配置，包内的计算脚本仅使用 Python 3 标准库。

**调用示例**

~~~text
使用 $crossborder-ecommerce-last30days，查美国小型网店卖家最近30天发货时的抱怨。
重点找反复出现的手工补救办法。匹配 Amazon US 在售商品，列出已能解决问题的替代品，
并说明哪些需求值得打样、哪些应排除、哪些还缺数据。
~~~

只想扫热点，可以改问“过去 30 天，德国养宠人群出现了哪些可能改变购买行为的事件？”已有产品时，可以改问“以英国市场为例，帮我验证低桌面用的标签纸收纳器是否已有足够好的替代品。”

## 一次研究会交付什么

| 卖家要判断的问题 | 可检查的产出 |
|---|---|
| 最近发生了什么，跟谁有关？ | 时间窗、事件或讨论原文、目标人群和实际覆盖的平台 |
| 用户在哪一步遇到障碍？ | 按独立经历去重的抱怨、现有补救办法及支付意向证据 |
| 有没有现成商品能解决？ | 目标站真实商品链接、关键规格、替代方案、未解决或已解决的部分 |
| 现在值得打样吗？ | 单件贡献及缺项、最可能推翻方向的证据、下一项测试和通过条件 |

## 来源与改动

**本技能根据 Matt Van Horn（GitHub 用户 @mvanhorn）的 last30days-skill 修改而成。** 沿用其近 30 天、多平台、可回溯原始讨论的研究方法。原项目按 MIT 许可证发布，原作者版权声明与许可全文随包保留。[原项目](https://github.com/mvanhorn/last30days-skill) · [随包许可](LICENSE)

本版独立编写了跨境选品流程、商品匹配与竞品反证、单件成本工具和中文交付模板。用户可选用原项目采集数据，也可用已获准访问的公开来源。采集引擎由原项目单独维护。
